C3 連線試用

本版本使用同一個 Wi-Fi 熱點，不需要 Vercel。網頁和韌體必須使用同一版本。

1. 燒錄韌體

  1. 將電池盒電源關閉並斷開，先將車輪架空；使用 USB 資料線連接 C3 與電腦。
  2. 用電腦的 Chrome 或 Edge 打開 HTTPS 網站，按「連線」→「USB」→「第一次使用或更新韌體」→「燒錄小車韌體」，選擇 C3 的 USB 序列埠。
  3. 等待進度完成並驗證。若燒錄失敗，可按住 BOOT、按一下 RESET，再放開 BOOT 後重試。

燒錄會取代板子上的程式，不會主動清除整片快閃記憶體；先前若有不同的分割配置，儲存資料可能仍會受影響。燒錄完成後可繼續設定 Wi-Fi。

也可下載 RoverC3.ino，使用 Arduino IDE 與 esp32 3.3.12、WebSockets 2.7.2 手動燒錄；板型選 ESP32C3 Dev Module，USB CDC On Boot 設為 Enabled。

2. 設定熱點

  1. 開啟 2.4 GHz 手機熱點；C3 不支援 5 GHz Wi-Fi。Wi-Fi 密碼會儲存在 C3 上。
  2. 用電腦 Chrome 或 Edge 開啟 HTTPS 版網頁，按「連線」→「USB」→「連接 USB」，選擇 C3 的 USB 序列埠。
  3. 輸入熱點名稱和密碼，按「送出 Wi-Fi 設定」；如果 Wi-Fi 沒有密碼，密碼欄位留空。連線成功後，IP 和 6 位數配對碼會自動填入。已設定過時可按「連接 USB」查詢。
  4. 按「結束 USB」，拔除 USB，然後接上電池並開啟電源。板子會記住熱點設定，重新連線後 IP 可能改變；如有變更，重新透過 USB 讀取。

3. 多人連線

  1. 所有手機和小車必須在同一個網路。輸入小車目前的 IP 與配對碼，按「連線」。瀏覽器若要求區域網路權限，請允許。
  2. 第一位按「取得控制權」。其他人連上後可等待；需要交接時，操作者按「交出控制權」，下一位再按「取得控制權」。
  3. 可用「分享連結」分享 IP；配對碼需另外交給組員。IP 變更時，連結需重新分享。

4. 實車測試

  1. 先確認 LM2596 輸出 5V，且 DRV8833 的腳位與休眠設定符合實際板子。韌體的訊號腳為 GPIO4→IN1、GPIO3→IN2、GPIO1→IN3、GPIO0→IN4。
  2. 車輪架空，先在校正頁分別測試 A、B 與左右輪方向，再用低速測試直走。更新後先重新校正一次；左右對應、方向與直線微調會儲存在小車，其他裝置接手時自動使用。原本存在手機的校正不會自動匯入。
  3. 驗證停止、交出控制權與斷線停止後，再把小車放到地面。小車移動時約 650 毫秒沒收到持續指令會停止並釋放控制權。

此版本尚未在你的實體板子及手機上測過。手機熱點需允許連入設備彼此通訊；HTTPS 網頁連本機 WebSocket 的行為可能因手機和瀏覽器而異。若無法連線，請記錄手機、瀏覽器和熱點型號。
