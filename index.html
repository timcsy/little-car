組裝與接線

連線

連到小車所屬的區域網路，可以控制小車和分享作品。例如：同一個手機熱點或教室網路。

尚未連線

掃碼加入小車；請只分享給同組組員。

加入小組

不需要在同一個區域網路，只要能連上網際網路，就可以和組員分享作品。輸入同組小車的配對碼；第一台電腦讀取小車後會自動建立小組。

尚未加入小組

配對碼提醒

小組使用公開配對服務；6 位數配對碼不適合作為保密憑證。請確認核對碼，只允許同組組員加入。

USB 設定小車

USB 用來讀取小車、設定 Wi-Fi 和燒錄韌體。遙控與校正請使用「區域網路」分頁的網路連線。

1 開啟 USB

用電腦版 Chrome 或 Edge。先關閉並斷開電池電源，再用 USB 資料線連接小車。

「結束 USB」只會關閉網頁的 USB 通訊。

2 輸入 Wi-Fi

3 前往網路連線

讀取成功後，IP 和配對碼會填入「區域網路」分頁；要控制小車的裝置須能透過網路連到小車。

掃碼加入小車；請只分享給同組組員。掃描裝置需要能連到小車的區域網路。

先用 USB 連接小車，並按「連接 USB」。

第一次使用或更新韌體

先關閉電池盒開關，再用 USB 連接電腦。更新後請重新校正一次，設定會儲存在小車。
